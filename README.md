# 디두와 그니의 결혼 가계부💸

구글 시트 「결혼예산·지출기록」을 데이터베이스로 쓰는 PWA입니다. 휴대폰 홈 화면에 설치해서 앱처럼 씁니다.

```
[web: React PWA] ──POST(text/plain JSON)──▶ [gas: Apps Script 웹앱] ──▶ [구글 시트]
```

- `gas/`: Apps Script API (PIN 인증, 지출/체크리스트 CRUD, 데이터 규칙, 설정)
- `web/`: React + Vite + TypeScript + Tailwind, TanStack Query, vite-plugin-pwa

## 1. GAS 준비

1. **시트를 먼저 백업하세요.** 시트에서 `파일 > 사본 만들기`. `setup()`이 데이터 확인 규칙을 바꿉니다.
2. 시트에서 `확장 프로그램 > Apps Script`를 열어 시트에 연결된 스크립트를 만듭니다.
3. `gas/src`의 파일을 올립니다. 둘 중 하나로 하면 됩니다.
   - **직접 복사:** 편집기에 같은 이름의 파일을 만들어 붙여넣습니다. `appsscript.json`은 `프로젝트 설정 > "appsscript.json" 매니페스트 파일 표시`를 켜야 보입니다.
   - **clasp:** 아래 명령을 차례로 실행합니다.
     ```bash
     npm i -g @google/clasp
     ```
     ```bash
     clasp login
     ```
     `gas/.clasp.json.example`을 `gas/.clasp.json`으로 복사하고 스크립트 ID를 넣은 뒤, `gas/` 폴더에서 올립니다.
     ```bash
     clasp push
     ```
4. `프로젝트 설정 > 스크립트 속성`에 `gas/.env.example`의 값을 등록합니다. 최소 `PIN`(6자리 숫자)은 필요합니다.
5. 편집기에서 `setup` 함수를 선택해 **실행**합니다. 처음 실행할 때 권한 승인이 뜹니다. 실행 로그에서 아래 작업 결과를 확인하세요.
   - 「예산·지출 기록」에 `ID` 열 추가와 기존 행 ID 채우기
   - 시트 6개 생성: 목록, 목록_속성, 설정, 분류예산, 체크리스트, 삭제기록
   - 지금 쓰던 드롭다운 값을 「목록」 시트로 옮기기
   - 데이터 확인 규칙을 「목록」 범위 참조로 바꾸기
6. `배포 > 새 배포 > 웹 앱`으로 배포합니다.
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - 배포가 끝나면 나오는 `…/exec` URL을 복사합니다.

> 코드를 고친 뒤에는 `배포 관리 > 수정(연필) > 버전: 새 버전`으로 올려야 URL이 그대로 유지됩니다.

## 2. 웹 실행

`web/` 폴더에서 차례로 실행합니다.

```bash
cp .env.example .env
```

`.env`의 `VITE_GAS_URL`에 위에서 복사한 URL을 넣고, 패키지를 설치합니다.

```bash
npm install
```

```bash
npm run dev
```

- `.env`에는 GAS URL만 넣습니다. **PIN은 넣지 마세요.** `VITE_` 값은 빌드된 JS에 그대로 노출됩니다.
- 서비스 워커(PWA)는 빌드본에서만 동작합니다. 확인하려면 `npm run build` 후 `npm run preview`를 실행하세요.

## 3. 배포 (Vercel)

1. 저장소를 GitHub에 올리고 Vercel에서 import합니다.
2. **Root Directory**를 `web`으로 지정합니다.
3. **Environment Variables**에 `VITE_GAS_URL`을 추가합니다.
4. 배포합니다. `vercel.json`이 새로고침할 때 SPA 라우팅을 처리합니다.

## 4. 휴대폰에 설치

- **iPhone:** Safari로 접속 → 공유 버튼 → `홈 화면에 추가`
- **Android:** Chrome으로 접속 → 설정 탭의 `설치` 버튼, 또는 메뉴 → `앱 설치`

## 보안 구조

- PIN은 GAS 스크립트 속성에만 있고, 비교도 서버에서만 합니다.
- 5회 틀리면 10분 잠금. 잠금을 풀려면 GAS 편집기에서 `resetPinLock()`을 실행합니다.
- 로그인하면 랜덤 토큰을 받습니다. CacheService에 저장되고 최대 6시간 유지되며, 쓰는 동안은 연장됩니다.
- 토큰은 sessionStorage에 둡니다. 다음 경우 PIN을 다시 입력합니다.
  - 앱을 완전히 종료했을 때
  - 백그라운드에 5분 넘게 있었을 때
  - 설정한 시간 동안 조작이 없었을 때
- 서비스 워커는 화면 파일만 캐시하고, 지출 데이터(API 응답)는 캐시하지 않습니다.
- 시트 자체의 "링크가 있는 모든 사용자" 공유는 꺼 두는 걸 권장합니다.

## 시트 구조

| 시트 | 용도 |
|---|---|
| 예산·지출 기록 | 기존 지출 시트 + `ID` 열. 헤더 이름으로 찾기 때문에 열 순서를 바꿔도 됩니다 |
| 목록 | 분류 / 결제한 사람 / 진행상황 / 현금영수 처리상태 드롭다운 원본 |
| 목록_속성 | 항목별 색상, 집계구분(완료/예정/제외), 예산포함 |
| 설정 | `weddingDate`, `totalBudget` |
| 분류예산 | 분류별 예산 |
| 체크리스트 | ID, 제목, 그룹, 마감일, 완료, 담당, 메모, 순서 |
| 삭제기록 | 앱에서 삭제한 행을 JSON으로 보관 (복구용) |

- `총 견적` 열에 수식이 있으면 앱은 그 칸에 값을 쓰지 않습니다. 새 행에는 바로 위 행의 수식을 이어 붙입니다.
